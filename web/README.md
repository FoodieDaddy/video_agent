# 片场 Studio 前端

默认中文、无构建步骤的 ES module 控制台，由现有 FastAPI 静态目录提供。视觉采用冷白画布、半透明玻璃侧栏、独立白色卡片与石墨色操作，电影氛围图以卡片内图片呈现。页面无需在运行时访问字体或图片服务。

## 页面与模式

- `/`：默认连接同源 `/api/v1`，读取实际项目；用户提交的新建与修改会写入后端。`/?mode=live` 同样有效。也可在“工作室设置”中设置 API 根地址和现有开发身份；连接设置只在内存中保存，不保存模型密钥。
- `/?mode=demo`：显式进入示例空间。项目、人物、场景、分镜、任务和审核均为内存示例；顶部与页脚明确标记。刷新会恢复初始示例资料，新建或修改不写入后端。
- `/legacy/index.html`：迁移期间保留的经典控制台，包含完整的旧版本操作。它直接连接后端，并非新版示例模式。

页面与接口层共用 `api.js` 导出的 `resolveMode(search)`；页面直接 `createStudioApi()`，避免维护两套默认规则。没有 `mode`、`mode=live`、空值或未知 URL 查询值均使用真实模式，只有精确 `mode=demo` 进入演示。显式配置 `mode:'demo'` 或 `mode:'live'` 优先于 URL；显式非法配置抛出 `invalid_mode`，防止拼写错误被静默接受。适配器导入与构造不自动发请求，页面调用读取方法时才读取后端。

主要入口为创作概览、项目库、素材管理、智能体团队、审核中心与设置。项目内保留剧本、人物、场景、导演、分镜、视频、声音、剪辑、评估、审核和模型配置页签。复杂媒体版本操作仍可进入经典工作台。

剧本页是独立的正文工作区：可手动新建/编辑，导入TXT、MD、JSON、DOCX，保存为新版本，预览并复制恢复历史。AI辅助支持润色和续写，基于已保存版本确认提交；续写保留原稿再追加新段。小说上传与解析保留独立入口，不和导入已有剧本混用。完整约定见[剧本工作区](../docs/development/script-workspace.md)。

保存状态常驻编辑器底部，普通保存不弹出全局提示；无修改时不追加版本。支持 Cmd/Ctrl+S，保存期间继续输入的文字保留为草稿。导入错误在当前弹窗内显示；真实版本冲突先保留草稿，核对最新版本后才能另存。后续制作提醒默认收起。

“专注写作”收起导航和辅助面板，保留同一份草稿、选区和正文滚动；Escape 或退出按钮返回原页面位置。弹窗打开时 Escape 优先关闭弹窗，输入法取消候选不退出写作。手机保存栏紧凑为 66px，并提供 AI／历史面板快捷入口与返回正文路径。关闭弹窗后焦点回到原操作控件，重绘后按同一控件身份恢复，避免跳到另一个项目。

示例生成只记录演示任务，不伪造生成后的真实媒体。真实模式不自动补示例图片或虚构进度；缺少数据时显示空状态。启动和切换连接不触发模型生成，生成操作经确认后提交；审核默认只保存结论，`resume_workflow=false`。

全局搜索支持 Ctrl/Cmd+K、上下键与 Enter，Escape／Tab／选择或路由跳转后收起；搜索结果在手机保持视口安全距离，手机输入为 16px、44px 高。概览手机布局优先呈现实际项目，阅读入口只读展示已有正文，手写稿不要求先有模型梗概。

项目库区分真正空库与筛选无匹配，提供清除筛选、已载入／显示计数，以及最近更新、创建时间、名称排序；卡片进入再返回保留列表上下文与焦点。素材库按真实 MIME 分类，名称读取 `meta.filename`，未提供时间时不虚构日期；可搜索名称、筛选类型、默认或按名称排序。详情可沿当前筛选结果前后浏览，关闭返回最初卡片。

## 文件职责

| 文件 | 职责 |
| --- | --- |
| `index.html` | 页面骨架、导航、可访问入口和原生 dialog 容器 |
| `styles.css` | 设计变量、组件样式、响应式断点和减少动画支持 |
| `app.js` | 路由、交互、请求生命周期、弹窗和任务轮询 |
| `views.js` | 纯展示函数；不直接请求或触发生成 |
| `api.js` | 统一 URL、身份头、错误、取消、SSE 和真实/示例适配 |
| `demo-data.js` | 每个适配器独立的内存示例及本地插图 |
| `script-editor.js` | 正文字段、按连接/身份/项目隔离的会话草稿、版本冲突与保存结果合并 |
| `focus-return.js` | 弹窗触发控件身份与可用性，支持重绘后的焦点返回并限制项目作用域 |
| `search-controller.js` | 全局项目／功能匹配、键盘选择及搜索浮层水平边界规则 |
| `project-library.js` | 已载入项目的筛选、搜索与只读排序规则 |
| `asset-library.js` | 素材真实元信息、分类、筛选、名称排序与连续预览位置 |
| `icons.js` | 固定 SVG 图标，不依赖图标 CDN |
| `assets/` | 原创电影图、本地 Manrope 字体与许可证 |
| `tests/` | Node 内置测试，验证接口契约和展示边界 |

新增界面操作先定义适配层方法，再由控制器调用；展示函数不拼接请求。所有用户/服务端文本经转义，媒体地址检查协议。跨项目加载取消旧请求并清除旧轮询；隐藏页面和卸载时停止轮询。异步表单完成只能关闭自己的弹窗，不能关闭用户后来打开的弹窗。

## 验证

Python 环境与启动沿用项目根指南，默认保持单实例。Node 22 及以上可运行前端测试，无需 `npm install`：

```bash
node --test web/tests/*.test.mjs
```

需要浏览器验收：桌面与手机布局、折叠菜单、搜索筛选、新建、编辑、审核、真实空数据、普通成员权限、请求失败和弹窗切换。网页测试结束关闭自己创建的浏览器和服务进程。

初版界面与玻璃主题已验证桌面和手机布局，历史记录见testing目录。剧本工作区已单独完成接口、版本、草稿及实际模型验证，结果见[2026-11-05工作区验收](../docs/testing/script-workspace-2026-11-05.md)。DEMO只在内存读TXT、MD和顶层含script_text的JSON，不解析DOCX；完整四格式解析使用真实后端。

后续交互、真实冲突和 DOCX 表格保真的复核见[本轮验收记录](../docs/testing/script-ux-iteration-2026-11-05.md)。后端主页面为 JS/CSS 入口与模块依赖注入同一内容修订号，普通刷新即可重验证资源；该机制面向当前原生模块目录，不是原子发布系统。导演历史查询的前端预留仍未对应真实后端详情接口，模块四尚未交付。

继续迭代的专注写作、键盘操作、响应式及原项目保护实测见[写作体验验收](../docs/testing/script-writing-refinement-2026-11-05.md)。

概览、键盘搜索、手机首屏与只读阅读的实测见[概览与导航验收](../docs/testing/overview-navigation-2026-11-05.md)。

项目库和素材库的三轮实测、字段准确性及返回路径见[项目与素材库验收](../docs/testing/project-asset-libraries-2026-11-05.md)。
