## 传输故障与焦点修复

首个网页导演请求遭遇 `RemoteProtocolError`。核对服务器地址、模型和凭据配置后，发现 HTTP 传输异常没有转换为现有 Agent 可重试的 ProviderError。已做最小适配：安全消息只包含供应商和异常类型，重试仍使用原预算；6 项 MockTransport 回归通过，后续网页成功运行也记录了重试次数。原失败任务没有删除或改写成成功。

关闭历史后快速移动焦点时，下一帧的旧恢复回调可能抢回旧按钮。以可见审核标题主动聚焦做了复现，随后增加主动焦点优先判断；修复后两帧仍保持在新标题，普通关闭继续返回原触发控件，新增回归通过。

两处核验脚本问题也已纠正：OpenAPI 实际占位符为 `{board_id}`；数据核对改为公开 HTTP 元信息契约，没有继续调用未导出的内部 helper。修正后重新完成整段网页与数据核对。另一次桌面脚本试图聚焦只在手机显示的快捷入口，未产生提审；最终回测使用可见控件并等待 pending 状态后才继续，未把该次失败计入通过。
