## 发现与改进

| 实际问题 | 本轮实现 |
| --- | --- |
| 导入弹窗由键盘打开，Escape 后焦点退回 BODY；历史请求还可能经历异步读取及页面重绘。 | 在触发按钮禁用前记录来源；Escape、关闭、取消、背景点击统一走弹窗关闭流程；原生 close 后下一帧恢复焦点。按连接、项目、路由、弹窗会话与交互序号限制恢复，防止旧回调抢焦。重绘后按稳定控件身份寻找同一版本按钮。 |
| 编辑时导航、AI 和历史同时占据注意力，缺少连续写作空间。 | 新增“专注写作”，将同一草稿和保存入口放入居中的稿纸布局。进入保留选区方向及正文滚动；退出返回原页面位置。保留退出按钮、Escape、保存快捷键，输入法取消候选文字不会退出。 |
| 390×844 下保存栏约 123px，遮占正文较多。 | 保存栏紧凑为 66px；保留字数、持久保存状态、44px 放弃和保存控件。手机放弃操作保留完整可访问名称，以图标呈现。 |
| 窄屏下 AI 与版本历史在正文之后，需要较长滚动。 | 正文上方增加“AI 辅助／版本历史”入口，进入时聚焦对应标题；面板内提供“返回正文”。标题与按钮共用 2px 系统焦点色。 |
| 确认放弃草稿后，原触发按钮变为禁用，不能作为返回焦点。 | 明确将焦点交回正文，方便继续写作；已保存版本不变。 |

专注模式只改变布局，不创建第二份正文或另一条保存链路。切换项目、页签或连接时清除该布局状态；Ctrl/Cmd+K 退出专注后进入可见搜索框。刷新恢复普通布局，未保存草稿继续沿用既有 sessionStorage 隔离规则。

视觉上保持一套圆角、分隔线、文字色与按钮尺寸；进入动效只使用 220ms 的透明度和 4px 位移，尊重减少动画设置。界面没有加入新的装饰图片或外部字体请求。

### 键盘与异步验证

以下均通过真实页面断言：

1. Enter 打开导入，Escape 关闭后 `activeElement` 回到 `import-script`；点击关闭按钮也回到该按钮。
2. Enter 打开 V1 历史，在弹窗打开时通过现有路由处理器重绘工作区，旧按钮已断开；关闭后聚焦新 DOM 中同一个 V1 按钮。
3. 仅在浏览器内暂缓历史读取，随后用键盘打开导入，再放行实际 HTTP 读取；旧历史响应不会替换已打开的导入弹窗，关闭仍回到导入按钮。
4. 选区起点 34、终点 58、方向 backward，正文 scrollTop=250；进入专注均保持，页面切到顶部；退出后上述值保持，页面 scrollY 从 0 回到原先的 180。
5. 专注内打开“放弃草稿”确认窗，第一次 Escape 只关闭弹窗，保持专注；确认放弃后焦点回到 `script-text`。
6. 输入法组合状态的 Escape 不退出专注；Ctrl+K 退出并聚焦搜索；切换人物页后全局导航恢复。
7. 手机上 Enter 进入 AI 或历史面板，标题在视口内并获得焦点；Tab 到“返回正文”，Enter 回正文。标题和键盘按钮的计算焦点宽度均为 2px，颜色一致。

历史位于页尾、版本较少时，浏览器可能因页面已经滚到底部而无法把标题顶对齐。验收标准为标题可见、焦点正确、后续键盘路径可用，不要求人为增加空白以强制顶对齐。

## 响应式与截图

实测 320×700、375×812、390×844、768×1024、844×390 横屏、1440×1080：页面滚动宽度均等于视口宽度，无横向溢出；正文进入视口后保存按钮可见，保存／放弃控件高度至少 44px，互不重叠。三个手机宽度下保存栏均为 66px；平板及桌面为 72px。

桌面与手机分别检查普通和专注布局，查看截图后统一细化焦点线为 2px。减少动画模拟生效时，新增动画计算时长为 0.01ms。浏览器未记录未捕获页面错误。

最终实测使用前台 Chrome 测试会话。较早后台会话会延迟原生 close 与动画帧，相关等待没有作为通过证据；最终断言在可见页面完成。本轮手机验证是浏览器视口模拟，不等于 iOS 实机键盘验证。
