# 片场 Studio：白色玻璃卡片设计系统

日期：2026-11-04。目标是将暖色电影手册主题改为高级简约的白色玻璃卡片，沿用现有 ES module 页面和接口适配。

## 检索与取舍

实际执行 UI/UX Pro Max 的 `--design-system`，关键词为 `creative studio SaaS dashboard premium minimal white glassmorphism`，设计拨盘为差异 2、动效 2、密度 3；补充检索 `glassmorphism light white` 与对比度/触控/减少动画规则。

综合设计系统建议中包含深色配色和落地页布局，与用户明确要求的白色工作台不一致，因此只采用其极简留白、克制动效、玻璃材质与检查规则。实际实现使用既有原生 HTML/CSS/JS，不引入 Tailwind、React 或新的构建链。

玻璃感作用于表面，不降低文字整体透明度。主要说明色对 `#F5F7FA` 约 4.91:1，对 `#EFF2F6` 约 4.69:1；白字对石墨按钮约 14:1。图片上的装饰文字不代替正文说明。

## 组件与布局

- 白色玻璃侧栏与顶栏悬浮于背景，保留清晰的选中态与分隔。
- 四项统计拆为独立卡片；主要内容与右侧审核/动态保持稳定网格。
- 项目主视觉左侧使用白色内容面，右侧收纳电影图片；手机端改为图片在上、文字在下。
- 人物、素材、分镜、设置和弹窗统一中性颜色、圆角、边界与阴影。
- 正文使用不透明石墨/灰色，保留实际电影图和示例插图的内容颜色。
- 不支持 `backdrop-filter` 时，主要面板降级为不透明白色。

- 21 项前端契约与展示测试通过；控制器语法和差异空白检查通过。

- 浏览器未捕获页面错误；未调用模型或向实际项目写入测试内容。

## 2026-11-05 写作体验细化

继续沿用既有色彩与字体，以交互层级细化剧本页：普通布局保留辅助工具，专注布局居中呈现稿纸；工具按钮统一 44px 触控高度，手机保存栏压缩为 66px；标题、按钮及表单采用同一系统焦点色，键盘焦点线细化为 2px。减少动画偏好覆盖 220ms 的稿纸进入动效。

专注切换保留光标与滚动，弹窗关闭保留操作来源，窄屏面板提供明确返回路径。该轮的具体实测和范围见[写作体验验收](../testing/script-writing-refinement-2026-11-05.md)，不更改上文初版的历史测试数量。
