# 分段验收模块与流程步骤的对应

更新日期：2026-11-05。此处记录当前交付范围，业务目录和开发排期仍使用各自名称。

用户已明确选定：**模块四为“导演规划＋分镜创作＋第二轮审核（按当前生产流程继续）”**。这一明确范围优先于仅按手册步骤号推断模块号。

| 验收模块 | 当前范围 | 交付边界 |
| --- | --- | --- |
| 1 | 配置与模型基础 | 配置、Provider 与 LLM 探针 |
| 2 | 剧本 | 小说解析及独立剧本工作区：手写、导入、版本、润色、续写 |
| 3 | 人物／场景文字档案及第一审核 | 人物提取与描述、场景提取与描述、`characters_scenes` 审核 |
| 4 | 导演规划、分镜创作与第二审核 | 方案生成与历史、分镜／镜头编辑与版本来源、`storyboard` 提审及通过／退回；不自动进入媒体生成 |
| 5 | 角色形象、镜头视频与第三审核 | 用户已明确选择“角色形象＋镜头视频＋第三轮审核（按流程继续）”；在模块四功能与页面全部完成后接续 |

操作手册的分步生产表第 4／5 行分别是导演、分镜，这是模块四内部的两个生产步骤；`task.md` 产品能力条目也分开列出。`task.md` 第 12 章的“阶段 4 人物和场景、阶段 5 导演和分镜”则属于开发排期。它们都不能覆盖用户明确选定的验收模块范围。

当前生产 YAML 顺序为：剧本 → 人物与场景 → 第一审核 → 导演 → 分镜 → 第二审核 → 人物形象资产 → 镜头视频 → 第三审核 → 声音／剪辑等。模块四独立验证停在第二审核，后续媒体任务需要单独发起。

代码采用业务目录分层，`production` 同时容纳导演和分镜；目录数量不是验收编号。模块四继续沿用现有 Provider、任务和审核底座，不因此更换框架或复制执行循环。
